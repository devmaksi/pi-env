# Дизайн: pi-env — CLI-утилита управления окружениями pi

Дата: 2026-09-22
Статус: утверждена пользователем (этап 1)

## 1. Назначение

`pi-env` — интерактивная TUI-утилита для управления окружениями ИИ-агента `pi`.
Окружение pi — отдельная папка с конфигурацией агента (аналог `~/.pi/agent`):
`settings.json`, `extensions/`, `skills/`, `agents/`, `themes/`. Агент читает
конфигурацию из каталога, задаваемого переменной окружения `PI_CODING_AGENT_DIR`
(по умолчанию `~/.pi/agent`).

Задача CLI: редактировать, создавать и запускать окружения pi. Этап 1 — база
красивого интерфейса и AGENTS.md; функциональные действия (создание, запуск) —
заглушки, реализуемые в этапе 2.

## 2. Модель окружения

- Корневой каталог окружений по умолчанию: `~/.pi-env`.
- Окружение = подкаталог корня: `<root>/<имя>/`.
- Переопределение корня: флаг `--root <путь>` или переменная окружения `PI_ENV_ROOT`
  (флаг имеет приоритет).
- Любая подпапка корня — окружение; файлы, не являющиеся каталогами, игнорируются.
- По умолчанию каталог при старте не создаётся; при отсутствии — пустой список
  и подсказка в статус-баре.

Данные окружения (результат сканирования):

```ts
interface Environment {
  name: string;             // имя папки
  path: string;             // абсолютный путь (будущее значение PI_CODING_AGENT_DIR)
  hasSettings: boolean;     // есть settings.json
  hasSkills: boolean;       // есть skills/
  hasExtensions: boolean;   // есть extensions/
}
```

## 3. Стадии (этапы)

### Этап 1

Работает:
- реальное чтение списка окружений из корневого каталога;
- верхний таб-бар: `Окружения | Настройки | О программе`, TAB циклически переключает;
- клавиши: ↑↓ (перемещение), ←→ (фокус колонок, широкий режим), TAB (вкладки),
  Enter (подтвердить), Space (toggle), ESC (назад/выход);
- две колонки: слева список окружений + разделитель + пункт `Создать`;
  справа — краткая информация о выбранном окружении (заглушка);
- адаптивность: ширина < 62 колонок → правая колонка не отображается;
  SIGWINCH → перерисовка;
- статус-строка с легендой клавиш;
- AGENTS.md проекта.

Заглушки:
- Enter на окружении → суб-экран «Запуск окружения <имя> — этап 2»;
- Enter на «Создать» → суб-экран «Создание окружения — этап 2»;
- вкладка «Настройки» — минимальная: путь корневого каталога (инфо) и toggle
  «Цветной вывод» (рабочий, демонстрирует Space); правая панель — заглушка.

### Этап 2

- запуск окружения: spawn `pi` с `PI_CODING_AGENT_DIR=<путь окружения>` в текущей
  рабочей директории (после выхода pi CLI завершается);
- создание окружения: форма с полем имени (Enter — ввод текста) → создание папки
  с дефолтным `settings.json`;
- редактирование окружения.

### Этап 3+ (определяется отдельным циклом)

полные настройки, удаление окружений, детальная инфо-панель.

## 4. Архитектура

Тонкий терминальный слой + чистое ядро. Всё, что можно тестировать без TTY, —
чистые функции.

```
pi-env/
├── AGENTS.md
├── package.json          bin: pi-env; тесты node:test
├── tsconfig.json
└── src/
    ├── index.ts          вход: аргументы (--root/--help), проверка TTY, старт
    ├── terminal.ts       raw-режим, чтение клавиш, SIGWINCH, NO_COLOR
    ├── environments.ts   scan(root) → Environment[]            (чистая)
    ├── layout.ts         computeLayout(width, height) → размеры (чистая)
    ├── state.ts          AppState + reducer: клавиша → новое состояние (чистая)
    ├── render.ts         render(state, envs, size) → строки ANSI (чистая)
    └── run.ts            цикл: чтение клавиши → reducer → render
```

Состояние приложения:

```ts
interface AppState {
  tab: 'envs' | 'settings' | 'about';
  focus: 'left' | 'right';       // активная колонка (только широкий режим, вкладка envs)
  selected: number;              // индекс в активном списке
  sub: 'create' | 'run' | null;  // суб-экран-заглушка
  colorToggle: boolean;
}
```

## 5. UI

### Макет (широкий терминал, ≥ 62 колонок), вкладка «Окружения»

```
┌────────────────────────────────────────────────────────────────┐
│ Окружения    Настройки    О программе                          │
├──────────────────────────────────┬─────────────────────────────┤
│ > dev                            │ dev                        │
│   prod                           │ Путь: ~/.pi-env/dev        │
│   test                           │ settings.json ✓            │
│ ───────────────────────────────  │ skills ✓                   │
│   Создать                        │ extensions ✓               │
├──────────────────────────────────┴─────────────────────────────┤
│ ↑↓ перемещение  ←→ колонки  TAB вкладки  Enter ОК              │
│ Space toggle  Esc назад/выход                                 │
└────────────────────────────────────────────────────────────────┘
```

- Левая колонка (вкладка «Окружения»): окружения по алфавиту → разделитель →
  `Создать`. Курсор — один индекс на весь список.
- Правая колонка: краткая информация о выбранном окружении (имя, путь,
  наличие `settings.json`/`skills`/`extensions`); при выборе служебного пункта —
  «Выберите окружение». Детализация — этап 2.
- Узкий терминал (< 62 колонок): одна колонка на всю ширину, правая панель не
  рисуется, ←→ неактивны, TAB работает.

### Вкладка «Настройки»

Левая колонка: `Корневой каталог: ~/.pi-env` (инфо, не переключается) и
toggle `Цветной вывод: [x]` (Space). Правая панель — заглушка
«Подробные настройки — этап 2».

### Вкладка «О программе»

Центрированный блок: `pi-env 0.1.0`, «CLI для управления окружениями pi»,
краткая легенда клавиш.

### Суб-экраны (заглушки)

Центрированная рамка с текстом («Запуск окружения <имя> — этап 2»,
«Создание окружения — этап 2»). ESC — назад к списку.

## 6. Маппинг клавиш

| Клавиша | Действие |
|---|---|
| ↑/↓ | перемещение в активном списке (envs: окружения + «Создать»; settings: пункты настроек) |
| ←/→ | переключение фокуса левая/правая колонка (только широкий режим, вкладка envs) |
| TAB | цикл вкладок: Окружения → Настройки → О программе; сброс суб-экрана и фокуса |
| Enter | окружение → суб-экран «Запуск — этап 2»; «Создать» → суб-экран «Создание — этап 2» |
| Space | на сфокусированном пункте настроек — flip toggle «Цветной вывод» |
| ESC | на суб-экране — назад к списку; на верхнем уровне — выход из CLI |
| Ctrl+C | аварийный выход |

Пункт «Настройки» в левой колонке отсутствует — только вкладки.
Ввод текста (поля форм) появляется в этапе 2; Enter на поле ввода — выбор поля.

## 7. Ошибки и краевые случаи

- Корневой каталог не существует → пустой список + «Окружения не найдены в <root>».
- Не TTY → stderr-сообщение, код выхода 2.
- Ctrl+C → корректный выход; SIGWINCH → перерисовка.
- Ширина < 30 → «Терминал слишком узкий» + одна колонка; высота < 8 → «Терминал слишком мал».
- Файлы (не каталоги) в корне игнорируются; неизвестные клавиши игнорируются.
- Нечитаемый корневой каталог → строка ошибки в статус-баре.

## 8. Тесты

`node:test` + TypeScript, без TTY — тестируется только чистое ядро.

- `scan(root)`: пустой корень, каталоги/файлы в корне, отсутствие `settings.json`.
- `computeLayout`: порог 62 колонки, узкий терминал, низкий терминал.
- reducer: TAB-цикл вкладок, открытие/закрытие суб-экранов, toggle, выход по ESC,
  границы списка (не выйти за 0 и N).
- `render`: детерминированные эталонные строки (широкий/узкий, суб-экраны, `NO_COLOR`).

## 9. Технологический стек

- Node.js ≥ 20, TypeScript.
- Ноль runtime-зависимостей: собственный ANSI-рендерер (raw-режим терминала).
- Сторонние dev-зависимости: только TypeScript и раннер тестов (tsx).
- Команды: `npm run build`, `npm test`, `node dist/index.js` (или `npx tsx src/index.ts`).

## 10. AGENTS.md

Корневой AGENTS.md проекта (на русском) содержит:
назначение CLI; модель окружения (`PI_CODING_AGENT_DIR`, корень `~/.pi-env`,
`--root`/`PI_ENV_ROOT`); статус этапа 1 и список заглушек; стек; команды
(build/test/run); структуру проекта; конвенции (чистые функции для логики,
тонкий терминальный слой, UI и логи на русском, отсутствие runtime-зависимостей);
маппинг клавиш; дорожную карту.

## 11. Решения и допущения

- Путь корня: `~/.pi-env` (не `~/.pi/environments`) — отдельное дерево, чтобы не
  путать с реальным конфигом агента `~/.pi/agent`.
- Порог адаптивности — константа 62 колонка (тестируется).
- Сортировка окружений — алфавитная по имени.
- Цвета: ANSI, уважение `NO_COLOR`; активный таб — яркий цвет, выбранный пункт —
  инвертированная строка.
- Версия 0.1.0 (этап 1).
