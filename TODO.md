## 3. UX и клавиши

- [ ] Значения с ограниченным выбором (enum-строки формы) переключать стрелками
  ←/→ прямо на строке, без Enter-режима. Сейчас «Тип» и «Exposure» в форме
  добавления MCP (`state-mcp.ts mcpFormStep`): Enter → курсор уходит в список
  значений → ←/→ или ↑/↓ → снова Enter, чтобы зафиксировать значение и вернуть
  курсор на строку формы. Итого два Enter и прыгающий курсор на каждую смену
  значения, а после смены «Типа» ещё и перестраивается набор строк формы
  (`mcpFormRows`: stdio — команда/аргументы/директория, http — url).
  Целевое поведение: курсор стоит на enum-строке → ←/→ сразу меняют значение
  (со циклом по списку), ↑/↓ — по-прежнему переход между строками формы,
  Enter — только submit/действие. Сейчас ←/→ на такой строке не делают ничего
  (`if (!textRow) return { kind: 'form', form }`). Цена правки: `mcpFormStep`,
  подсказка клавиш («←/→ — значение», новый ключ в `src/locales/*.json` рядом
  с `hint.select`), тесты в `test/state-mcp.test.ts`. Относится ко всем
  закрытым спискам значений; пикеры со свободным списком («Модель»/
  «Инструменты»/«Скиллы»/«MCP») остаются как есть.
- [ ] Поиск/фильтр по списку окружений (`/`): печатные клавиши сейчас
  работают только в полях формы и в пикере пакетов.
- [ ] Клонирование окружения (`C` в списке): «сделать вариацию текущего» —
  копирование каталога + settings; сейчас окружение можно создать только
  с нуля из main-агента.
- [ ] `q` для выхода вместо мгновенного ESC-выхода (`state.ts onEsc`:
  ESC на главном экране = `quit: true`) — легко потерять сессию промахом
  ESC; ESC оставить только «назад из суб-экрана».
- [ ] `?` — контекстная справка клавиш текущей вкладки (overlay). Сейчас
  клавиши описаны одной строкой `about.keys` на вкладке «О программе»,
  подсказки (`hints`) — только в busy-видах.
- [ ] Быстрые переходы: цифры `1–5` для вкладок, `g`/`G` верх/низ списка,
  `h`/`j`/`k`/`l` как ←/→/↑/↓.
- [ ] ASCII-фолбэк маркеров (`✓ ⚠ ✗ ↑ ↓ — …`): ambiguous-width задокументирована
  в AGENTS (в одном терминале ＋ = 2 клетки, ↑ = 1). Настройка/`PI_ENV_ASCII=1`
  (`OK`/`!!`/`XX`) снимает и проблему резерва у границ колонок.
- [ ] Статус после дочернего `pi` (`pirun.ts launchPi`: «любой exit означает
  возврат в TUI»): показать код выхода и длительность сессии в статус-строке.
